# BIRD BLAST
1. Create a GitHub repo and push this whole folder (including the hidden `.github` folder).
2. Open the repo -> Actions tab -> "Build BIRD BLAST APK" (runs automatically on push, or press "Run workflow").
3. When it turns green, open the run -> Artifacts -> download `BIRD-BLAST-apk` -> unzip -> install `BIRD-BLAST.apk`.
